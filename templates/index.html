Performance Insights

🧠

Transformer-VAE Superiority

The Transformer-VAE architecture (FID=28.17) outperforms traditional VAE (FID=36.21) and standard Autoencoders (FID=72.36). By processing the image in patches, the Multihead Self-Attention layer retains high-frequency details (such as mucosal tissue texturing and vascular structures) that are typically averaged out in standard convolutional bottlenecks.

⚡

Perceptual Loss Efficacy

Integrating VGG-16 Perceptual Loss (comparing activation features instead of raw pixel values) pushes reconstructions away from blurry averaging. Models trained with Perceptual Loss achieve slightly lower SSIM metrics on paper but yield significantly better visual sharpness and lower FID scores.

Anomaly Detection Playground

This module screens for anomalous tissue structures (e.g. polyps, ulcers, esophagitis) using an Autoencoder model trained exclusively on normal frames (`normal-cecum`, `normal-pylorus`, `normal-z-line`). Since the model lacks representations for diseased tissue, it yields elevated reconstruction errors on anomalies, creating a natural screening boundary.

Downstream Classification

To evaluate the clinical utility of our synthetic images, we trained a downstream Vision Transformer (ViT) classifier under two settings: using purely real images vs. using a hybrid dataset augmented with synthetic images generated by our Transformer-VAE.

Training Data Accuracy ↑ Precision ↑ Recall ↑ F1-score ↑ AUC ↑
Real Only 0.842 0.821 0.804 0.812 0.887
Real + Synthetic 0.901 0.889 0.876 0.882 0.941
📊

Project Information

GastroLens is a final year computer engineering B.Tech project focusing on Generative AI framework optimization for synthetic GI endoscopy image synthesis.

Medical image classification often fails due to extreme data scarcity and privacy restrictions. By generating synthetic samples, we augment local hospital dataset pools, resulting in stronger downstream classification accuracy.
